# contact-graphic

แจกฟรี **แบบช่องทางการติดต่อ สไตล์พิ้งจู พรีเมี่ยม**
โดย **ferilncia.a**

สามารถนำไฟล์/ดีไซน์ในโปรเจกต์นี้ไปใช้งานได้อย่างอิสระ ทั้งงานส่วนตัวและงานเชิงพาณิชย์

## ✨ สิทธิ์การใช้งาน

คุณสามารถ:

* ใช้ในงานส่วนตัวได้
* ใช้ในงานเชิงพาณิชย์ได้
* ใช้กับเว็บไซต์ ร้านค้า เพจ หรือธุรกิจได้
* นำไปแก้ไขและปรับแต่งให้เข้ากับงานของคุณได้
* นำไปเป็นส่วนประกอบของผลงานอื่นได้

## ⚠️ ข้อกำหนด

**ห้ามคัดลอกดีไซน์ทั้งหมดไปเผยแพร่หรือแจกต่อโดยไม่มีการปรับเปลี่ยน**

หากต้องการนำไปใช้เป็นส่วนหนึ่งของผลงานของคุณ กรุณา **ปรับเปลี่ยนองค์ประกอบของดีไซน์บางส่วน** เช่น สี ฟอนต์ การจัดวาง รูปแบบกราฟิก ข้อความ หรือองค์ประกอบอื่น ๆ เพื่อให้เกิดความแตกต่างจากต้นฉบับ

ไม่อนุญาตให้นำไฟล์ต้นฉบับหรือดีไซน์ทั้งหมดไป:

* แจกจ่ายต่อในลักษณะเดียวกับต้นฉบับ
* อัปโหลดเพื่อแจกเป็น Resource ของตนเอง
* จำหน่ายต่อโดยอ้างว่าเป็นผลงานที่สร้างขึ้นเองทั้งหมด
* นำไปสร้างบริการหรือสินค้าในลักษณะที่ทำให้เข้าใจว่าเป็นเจ้าของต้นฉบับ
